NepalCivic

Smart Municipal Issue Management System

NepalCivic is a web-based civic engagement platform that allows citizens to report local municipal issues, track their resolution, and participate in community decision-making. It improves transparency and efficiency between citizens and local authorities by centralizing issue reporting and management.

🚀 Features
📸 Issue Reporting – Citizens can report local problems with images and descriptions
🗳️ Voting System – Users can vote on important civic issues to prioritize them
🔔 Real-time Notifications – Stay updated on issue status changes and announcements
📍 Issue Tracking – Track progress from reported → in review → resolved
🏛️ Admin Dashboard – Ward/admin staff can manage, assign, and resolve issues efficiently
📊 Centralized Management – All reports organized for better transparency and control
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Server: Apache (XAMPP/WAMP recommended)
